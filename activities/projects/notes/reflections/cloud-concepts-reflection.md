Reflection Paper: Cloud Computing Concepts
Cloud computing has become an important part of my daily life because I use different online applications for communication, learning, and storing files. Three cloud services that I regularly use are Google Drive, Messenger, and Canva. Google Drive helps me store and access my school files from any device. Messenger allows me to communicate with classmates and friends instantly, while Canva helps me create presentations, posters, and other school projects online.
All three services are examples of Software as a Service (SaaS) because they provide ready-to-use applications over the internet without requiring users to install or manage the underlying infrastructure. They are also mainly deployed using the Public Cloud model because anyone with an internet connection and an account can access these services. I chose this classification because users only interact with the application, while the service providers handle the servers, storage, updates, and security in the background.
Git and GitHub are also essential tools when working on cloud projects. Version control is important because it records every change made to a project, making it easier to fix mistakes or return to an earlier version if something goes wrong. GitHub improves collaboration by allowing multiple team members to work on the same project without overwriting each other's work. Features such as branches, pull requests, and commit history help organize changes and make teamwork more efficient. In cloud infrastructure management, GitHub also supports Infrastructure as Code (IaC), where configuration files are stored and tracked just like source code. This reduces errors, improves consistency, and makes deployments more reliable.
Overall, this lesson helped me understand that cloud computing is more than just online storage. It includes different service and deployment models that support modern applications and businesses. Learning about Git and GitHub also showed me how important version control is in managing cloud-based projects. These concepts will be valuable as I continue studying information technology and preparing for future careers in the IT industry.
